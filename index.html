DEIMONYAG

THE DEMON ON THE TRACK

Robot seguidor de línea de competición desarrollado alrededor de una ESP32-C3, 12 sensores QRE1113GR, tracción dual con IFX9201SG y un sistema de succión mediante EDF27.

Diseñado para competir

Deimonyag combina control rápido, sensado analógico de alta densidad y succión activa para aumentar la carga normal sobre la pista y aprovechar mejor la adherencia disponible.

DESARROLLO

Un proyecto pensado por módulos

La electrónica, el firmware y las herramientas de diagnóstico se desarrollan por bloques. Existen programas de prueba independientes para motores, EDF27 y LED, además de una interfaz Python para pruebas de banco y telemetría.
